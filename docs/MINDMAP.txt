## 📚 第一层：底层原理（地基）

```

  ├── 渲染引擎

  │   ├── CSS 解析 → CSSOM 树
  │   ├── 合成 → Render 树
  │   ├── 布局（Layout）

  │   └── 合成（Composite）

  │   ├── 词法分析
  │   ├── 语法分析
  │   ├── 字节码生成
  │   ├── JIT 编译
  │   └── 执行
  └── 网络层
      ├── DNS 解析
      ├── TCP 连接
```

```
JS 核心概念
```
