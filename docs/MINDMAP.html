📖 学习路径建议

顺序：

  1. 闭包 → 理解作用域链
  2. 事件循环 → 理解异步机制
  3. Promise 原理 → 手写实现
  4. this 指向 → 理解调用方式
  5. 原型链 → 理解继承

🟡 框架进阶（P1）

顺序：

  1. React Hooks → useState/useEffect
  2. 虚拟列表 → 性能优化
  3. 自定义 Hooks → useDebounce/useThrottle
  4. Error Boundary → 错误处理
  5. TypeScript 泛型 → 类型安全

学习时间：2-3 周

顺序：

  1. SSE 流式对话 → 基础能力

  4. 多会话管理 → IndexedDB

💡 思维体系构建原则

1. 金字塔原则

  • 底层原理 → 语言核心 → 框架实战 → 业务应用
  • 先地基，后建筑

2. 关联原则

  • 知识点不孤立
  • 横向关联（同层级）
  • 纵向贯通（跨层级）

3. 实战原则

  • 理论 → 代码 → 项目
  • 每个知识点有实际应用场景

4. 迭代原则

  • 先广度，后深度
  • 持续更新，终身学习
