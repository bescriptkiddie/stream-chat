虚拟列表（仅渲染可见区域 + 缓冲区）

💡 核心原理

  • • 计算容器可见区域的起始和结束索引
  • • 仅渲染可见区域 + 上下缓冲区的元素
  • • 使用 transform 偏移实现滚动效果
  • • 大幅减少 DOM 节点，提升渲染性能
  • • 适用场景：长列表、表格、聊天记录等

🧠 思维体系定位

📍 在前端体系中的位置

第四层：应用场景→性能优化→长列表优化

虚拟列表是前端性能优化的经典方案，属于应用层的核心技术。 它通过只渲染可见区域来解决长列表性能问题，是大数据展示、聊天记录等场景的必备技术。
