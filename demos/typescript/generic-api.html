泛型封装 API - TypeScript 实战

深入理解泛型在实际项目中的应用

📚 泛型核心概念

什么是泛型？

泛型是类型的参数化，让代码可以适用于多种类型。

function identity<T>(arg: T): T {
  return arg;
}

identity<number>(42);
identity<string>("hello");

为什么用泛型？

  • • 类型安全：编译时检查
  • • 代码复用：一份代码多种类型
  • • 类型推断：自动推导类型
  • • 约束灵活：可添加类型约束

应用场景

  • • API 请求封装
  • • 数据结构（数组、映射）
  • • React Hooks 封装
  • • 工具函数库

泛型基础语法

1. 泛型函数

// 基础泛型函数
function identity<T>(arg: T): T {
  return arg;
}

// 使用
const num = identity<number>(42);    // 显式指定
const str = identity("hello");       // 类型推断

// 多个泛型参数
function pair<T, U>(first: T, second: U): [T, U] {
  return [first, second];
}

const result = pair<string, number>("age", 25);

2. 泛型接口

// API 响应接口
interface ApiResponse<T> {
  code: number;
  message: string;
  data: T;
}

// 使用
const userResponse: ApiResponse<User> = {
  code: 200,
  message: "success",
  data: { id: 1, name: "Alice" }
};

const listResponse: ApiResponse<User[]> = {
  code: 200,
  message: "success",
  data: [{ id: 1, name: "Alice" }]
};

3. 泛型类

class DataStore<T> {
  private data: T[] = [];

  add(item: T): void {
    this.data.push(item);
  }

  get(index: number): T | undefined {
    return this.data[index];
  }

  getAll(): T[] {
    return [...this.data];
  }
}

// 使用
const userStore = new DataStore<User>();
userStore.add({ id: 1, name: "Alice" });
const user = userStore.get(0); // 类型是 User | undefined

4. 泛型约束

// 约束 T 必须有 length 属性
function logLength<T extends { length: number }>(arg: T): void {
  console.log(arg.length);
}

logLength("hello");        // ✅ 字符串有 length
logLength([1, 2, 3]);      // ✅ 数组有 length
logLength({ length: 10 }); // ✅ 对象有 length
// logLength(42);          // ❌ 数字没有 length

// 约束 T 必须有 id
interface HasId {
  id: string | number;
}

function findById<T extends HasId>(items: T[], id: string | number): T | undefined {
  return items.find(item => item.id === id);
}

🎤 面试场景模拟

面试官：为什么需要泛型？直接用 any 不行吗？

✅ 好的回答：

用 any 的问题：

function identity(arg: any): any {
  return arg;
}

const result = identity("hello");
result.toUpperCase();  // ✅ 编译通过
result.toFixed();      // ✅ 编译通过（运行报错！）
// any 失去了类型检查

用泛型的好处：

function identity<T>(arg: T): T {
  return arg;
}

const result = identity("hello");
result.toUpperCase();  // ✅ 编译通过
result.toFixed();      // ❌ 编译错误！
// 泛型保留类型信息

💡 关键：泛型提供类型安全 + 代码复用，any 只有代码复用

面试官：泛型约束 extends 是怎么工作的？

✅ 详细讲解：

// 1. 基础约束：T 必须有 length 属性
function logLength<T extends { length: number }>(arg: T): void {
  console.log(arg.length); // TS 知道 T 一定有 length
}

// 2. 接口约束
interface HasId {
  id: number;
}

function findById<T extends HasId>(items: T[], id: number): T | undefined {
  return items.find(item => item.id === id);
}

// 3. 多重约束
interface Comparable {
  compareTo(other: this): number;
}

function sort<T extends HasId & Comparable>(items: T[]): T[] {
  return items.sort((a, b) => a.compareTo(b));
}

// 4. keyof 约束
function getProperty<T, K extends keyof T>(obj: T, key: K): T[K] {
  return obj[key];
}

const user = { id: 1, name: "Alice" };
getProperty(user, "name");  // ✅ 编译通过
getProperty(user, "age");   // ❌ 编译错误：age 不存在

💡 extends 的作用：缩小泛型的范围，确保类型安全

  apiCall: (...params: P) => Promise<T>
) {
  const [data, setData] = useState<T | null>(null);
  const execute = (...params: P) => apiCall(...params);
  return { data, execute };
}

// 使用

🔥 可能的追问

追问 1：泛型的默认值如何设置？

→ function foo<T = string>(arg: T): T

追问 2：泛型类型参数可以互相引用吗？

→ 可以，如 function f<T, U extends T>(a: T, b: U)

追问 3：如何约束泛型必须是联合类型的一部分？

→ 使用 extends: function f<T extends 'a' | 'b'>(arg: T)

追问 4：泛型在运行时存在吗？

→ 不存在，TypeScript 编译后会擦除所有类型信息
